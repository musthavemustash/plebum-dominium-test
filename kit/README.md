# Plebum Dominium: current downloads and historical kit files

This directory retains historical kit assets. Older PDFs, slides and the recovery worksheet have not been reconciled with the current guide and are excluded from current offline tester ZIPs.

Start at https://musthavemustash.github.io/plebum-dominium-test/downloads.html for the current versioned packages and both guide paths. Use public fixtures and disposable test data only.

- `VERIFY.md` identifies the current standalone tools and matching files in the current offline packages.
- Verify a ZIP using its own versioned `SHA256SUMS.txt`, then run its included `verify_package.py` after extraction.
- All seven R4 tool and wordlist files are preserved. Earlier physical test results remain tied to their original packages and cases.
- Follow the current HTML guide and its testing instructions. Do not use the historical print packet, slides, worksheet or `tools-bundle.zip` as current beta-testing instructions.
- Current software releases and the separately recorded review/test versions are listed at https://musthavemustash.github.io/plebum-dominium-test/downloads.html#software-versions . Verify each exact upstream download using its publisher’s instructions.

Plebum Dominium teaches self-custody with offline software. Hardware signers are optional after checked metal backups. Public T6/T7 testing uses disposable paper records; metal is outside those tests.
