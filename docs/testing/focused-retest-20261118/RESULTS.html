Plebum Dominium · Public alpha · November 17–18, 2026

Windows and Tails tool results

November 17 · Windows dice converter

The personal Windows computer used the signed complete tester, plebum-complete-offline-tester-20261115-r1.zip. The tester checked the signature and ZIP checksum, then verified the 231 files in the extracted package. Screenshots 02 and 03 record those checks.

  • Chrome and Python each produced the expected 24 words for all eight reference inputs (01–08). Screenshots 15 and 17–31 record the results.
  • Both tools rejected the 255-bit input and the input containing an invalid character. Neither produced seed words for those cases. Screenshots 32–35 record the four rejections.
  • Chrome accepted the on-screen dice and the laptop’s number keys. Keys 1 through 4 produced 00011011. Undo removed the last pair, leaving 000110. Screenshots 10–13 cover the buttons, Clear, keyboard entry and Undo.

November 18 · Windows wallet-map recovery

Edge and the Python wallet-map tool each encrypted the same 50-byte public file, public-map.txt. Each tool then decrypted the file created by the other. Windows compared both saved outputs with the original using fc.exe /b.

  • Edge to Python passed. Python decrypted browser-map.asc into python-restored.txt. Screenshot 45 shows the exact byte match.
  • Python to Edge passed. Edge decrypted python-map.asc. Screenshot 48 shows the downloaded browser-from-python.txt matched the original byte for byte.

Both comparisons reported FC: no differences encountered. Earlier command-entry errors preceded the successful comparisons. The tester reopened the saved evidence copy and confirmed that its second line read Unicode: café. Screenshot 49 shows the tool locked again with both boxes unchecked. Screenshot 50 shows the original, both encrypted files and both restored files together.

November 18 · Physical keyboard on Tails

The tester reported starting Tails offline and used the laptop’s physical number keys in the local Tor Browser dice converter. Pressing 1, 2, 3 and 4 produced 00, 01, 10 and 11. Keys 5 and 6 appeared as skipped rolls and added no bits.

Keyboard entry passed. The photo shows 4/128 pairs, 8/256 bits and 00011011. The tester confirmed keyboard entry. The evidence filename assigned to this check is 51-Tails-Dice-Physical-Keyboard-PASS.png.
