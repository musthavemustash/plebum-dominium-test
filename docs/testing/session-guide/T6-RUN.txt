T6.1 SET UP AND RECORD THE BASELINE
Create a named TEST ONLY Single Signature HD wallet, Native Segwit (P2WPKH).
Import the checked 24-word BIP39 test seed through New or Imported Software
Wallet. Enable Use passphrase and enter the exact separately recorded value.
For the recorded Testnet4 account the derivation was m/84'/1'/0'. Confirm your
network, script type and account before accepting a derivation.
EXPECT: valid mnemonic checksum and the intended configuration.
Apply; any wallet-file encryption password is separate from the BIP39 passphrase.
Capture Settings with View Seed CLOSED: fingerprint, derivation, script, network.
Record three full receive addresses AND the first change address from Addresses.
New keys have their own fingerprint/addresses; do not copy the completed run's.

T6.2 CHECK THE PAPER AND PASSPHRASE

EXPECT: different wallet identity/addresses, possibly no error. An empty balance

T6.3 RESTORE AND FUND THE WATCH-ONLY WALLET
Fully shut down and restore from paper in a fresh offline Tails session without

On Windows, confirm Testnet4 and import those public details into a clearly
named watch-only wallet. Compare its full receive address with the offline

T6.4 FIRST SPEND WITH CHANGE
On Windows, prepare a small payment to a destination checked independently
(for example, the faucet's current return address). Leave enough change for
recovery spending. Keep exactly the intended recipient entries; remove an
accidental empty second entry. Use sats and review the TOTAL fee.
Open Create Transaction, review the recipient output and every change output.
Match change to the independently recorded wallet addresses. Account for:
  input total = payment + change + total fee
Follow WALLET-TRANSFER-CHECKS.txt. Finalize for signing, save the unsigned PSBT
on the data USB (example: T6-Testnet4-spend-01-unsigned.psbt), close its tab and
reopen that USB copy with File -> Open Transaction -> File. Verify it is unsigned.

Boot fresh offline Tails, restore from the original paper records and compare
the public baseline again. Open the saved PSBT inside Sparrow. Review full
recipient, amount, change ownership/address, total fee and All (Recommended)
sighash before Finalize Transaction for Signing -> Sign. Handle passwords
privately. EXPECT: the required signature and Save Final Transaction appear.
Save T6-Testnet4-spend-01-signed.txn to USB and reopen that saved copy. Verify
the same transaction and amounts. Check saved evidence, eject USB and shut down.

On Windows, first open Sparrow in Testnet4 and the intended watch-only wallet.
Open the signed file FROM INSIDE SPARROW, not by double-clicking the .txn file.
Check the network, full recipient, all outputs, total fee and transaction ID
