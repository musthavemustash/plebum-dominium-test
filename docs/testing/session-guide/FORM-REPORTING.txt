MAKE A LINK THAT REVIEWERS CAN OPEN
1. On the online computer, review the USB evidence folder. Make a separate
   upload folder containing only this public test: screenshots, SESSION-NOTES.txt,
   verifier/comparison output, and the public input/output files relevant to it.
   Do not upload the entire USB, unrelated folders, account information or secrets.
2. Open Google Drive. Choose New → New folder and name it for the task, date,
   OS and exact package identifier, for example T4-2026-11-13-Windows-20261113-r1. Upload the selected files
   into it (drag and drop or New → File upload). Wait for every upload to finish.
3. Right-click that evidence folder → Share. Under General access choose
   Anyone with the link, with role Viewer. This lets anyone holding the link
   read these public-test files. Use Viewer, not Editor. Click Copy link and Done.
4. Test the copied link in a private/incognito window while signed out. Open an
   actual screenshot and notes file. If it asks for access, fix the sharing
   setting before submitting. A work/school account may forbid link sharing;
   use another permitted file host or report the restriction. Do not submit a
   link to a local USB path such as file:/// or /media/amnesia/.
5. Paste the folder link into the form's "File hashes and additional evidence"
   field, if present, or the matching evidence/description field. Include the exact filenames for each subcheck and the full ZIP SHA-256.
   A ZIP of the evidence is optional; keep the screenshots readable individually.
   Keep the originals and the working link available during review.
