VERIFY WITH SPARROW
Download all three public verification files from:
https://musthavemustash.github.io/plebum-dominium-test/releases/20261115-r1/manifest.txt
https://musthavemustash.github.io/plebum-dominium-test/releases/20261115-r1/manifest.txt.asc

1. Open Tools > Verify Download in Sparrow.
2. Signature: manifest.txt.asc
   Manifest: manifest.txt
   Public Key: plebum-public.asc
   Release File: your downloaded ZIP
3. Expect Plebum Dominium Release Signing and a matched manifest hash.
   Repeat for each ZIP you use. Stop if either check fails.

FULL RELEASE KEY FINGERPRINT

Compare all 40 hexadecimal characters against a copy saved earlier or obtained
through an independently trusted channel. A key and fingerprint from this same
website do not provide independent identity evidence. The signer name alone
is insufficient. The key in this copy expires on November 14, 2027.

GNUPG (from the folder containing the public files and ZIPs)
gpg --show-keys --with-fingerprint plebum-public.asc
# Compare the fingerprint before importing.
gpg --import plebum-public.asc
gpg --verify manifest.txt.asc manifest.txt
sha256sum -c manifest.txt

Expect Good signature from the expected key and OK for each downloaded ZIP.
A newly imported key may have an ownertrust warning; compare its fingerprint.
On Windows, Get-FileHash -Algorithm SHA256 can calculate a ZIP's checksum;
compare all 64 characters against that exact filename in the verified manifest.
Missing ZIPs are reported separately when checking the whole list.

Keep an accurate clock. Stop on a bad or missing signature, unexpected key,
expired/revoked key or mismatched checksum. Offline copies cannot learn about
subsequent revocations or new releases. Then extract and run T1's per-file check.
Keep the ZIP, signed manifest, signature, public key and result with your evidence.

A valid signature and matching hash do not prove software safety, computer
isolation or successful wallet recovery. These packages remain public alpha.
No private signing key, passphrase or revocation certificate belongs on this site.
