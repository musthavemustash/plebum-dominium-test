Offline tester · Folder guide

Find your test files.

For the complete offline tester and website tools only ZIPs, your test tools and fixtures are inside public-tests. Follow these steps from the downloaded ZIP.

Use the supplied public test inputs. Enter inputs only while disconnected. Follow T2’s instructions for connected-state checks, and leave the safeguards in place.

1

Extract, then open the inner folder

Extract the whole ZIP before opening any tools. In the extracted destination, find and open plebum-offline.

Windows

Right-click the ZIP and choose Extract All…. Open the extracted destination, then open plebum-offline.

Tails

Use Files or the archive manager to extract the entire ZIP into a chosen folder. When extraction finishes, open plebum-offline.

Your system may create an outer folder named after the ZIP. Open that first if needed. Stop when you see START.html, README.txt and public-tests together.

  1. Extracted destination
  2. plebum-offline
  3. START.html

Open START.html in your browser. It is the starting page for the extracted package.

2

T1: check the whole package

Open a console or PowerShell in plebum-offline, the folder containing START.html. In Tails 7.16 Files, right-click empty space and choose Open in Console. Run its verify_package.py.

Current folder: plebum-offline
Windowspy verify_package.pyTails / Linuxpython3 verify_package.py

This is the checker for the complete extracted package. A matching checksum confirms that files match the supplied reference. Stop and report missing or mismatched files before running tools.

3

T2–T5: enter public-tests

Return to your file manager. Inside plebum-offline, open public-tests. Use the matching test tools and instructions inside this folder.

  1. plebum-offline
  2. public-tests

Here you will find TESTING.txt, RETEST-WINDOWS.txt, dice-converter.html, descriptor-tool.html, the Python tools and fixtures.

For commands in these testing instructions, open your console in public-tests. The path fixtures/public-map.txt means “the fixtures folder inside public-tests.” This folder also has its own verify_package.py, which checks only the focused test files.

Keep public output files in plebum-offline/public-tests/results/. Run comparison commands from public-tests, one folder above results. In Files, use the location bar to see your full path; your USB mount name may differ from another tester’s.

Keep screenshots together in one Evidence folder in your session folder on the data USB. Follow one action, photo, reviewer’s filename, then save before continuing. Use a written observation for private wallet steps. See the live photo-review directions; save them separately before going offline. Published ZIPs retain their original instructions.
