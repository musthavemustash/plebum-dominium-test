A private pointer to your recovery plan—not a wallet backup.

What this card is for

A short location record helps an authorized person find the complete instructions and required materials. It cannot replace at least two signing keys and the complete 2-of-3 wallet configuration.

Location information can help a thief too. Protect the card even though it contains no signing secrets.

Write these pointers offline

  • Wallet type: 2-of-3 multisig.
  • Where to find the complete recovery instructions.
  • Separate seed-backup locations and wallet-configuration location.
  • Trusted contact and date last reviewed.
  • Location of any separate decryption instructions, if required.

Write privately on paper. This page intentionally provides no form for entering real locations or secrets.

Never include these

No seed words, raw entropy, private keys, wallet passphrases, or decryption passwords on the card. Keep it separate from the materials it points to.

A descriptor can contain private keys; only a verified public-only export belongs in the non-signing configuration records.

Keep it current

Check that the intended person can follow the pointers. Update the record after moving a backup or changing the recovery plan, then account for obsolete copies.

The downloadable legacy card/PDF has not yet been reconciled with these revised instructions. Do not treat that older packet as a verified version of this page.

Recovery still requires verification: use the complete, rehearsed procedure. A list of locations, a device brand, or a derivation-path label is not sufficient by itself.
