Rehearse on testnet

← 10 · Metal and the mapStep 11 of 16 · Rehearse on testnet12 · Protect the wallet map →

Learn with disposable keys and test coins, then rehearse recovery too.

1. Select the test network

Sparrow documents Tools → Restart in Testnet. Confirm the network shown by your installed version, and use a server, faucet and explorer for that same network. Different test networks are not interchangeable.

Test coins are for practice. Do not send real bitcoin, pay for test coins, or give a faucet seed words or a passphrase. A faucet needs only the intended public receive address. Interfaces and services can differ from mainnet.

2. Build a separate practice wallet

Create three new disposable keys and a test-only 2-of-3 wallet. Label all records TEST ONLY. Keep the configuration and temporary test backups long enough to complete the recovery exercise. Never reuse these keys for real funds.

Verify the threshold, script type, all three cosigner public keys and their origins against independent signer records. A matching receive address alone does not prove the coordinator is trustworthy.

3. Receive, review and sign

Receive test coins at an address verified against the intended wallet, wait for confirmation, then follow Practice spend. Review destination, amount, fee and change before each signature.

Broadcast on the same test network. A confirmation shows that transaction was accepted; it does not prove every backup or signer combination works.

4. Recover from the test backups

Reconstruct the disposable wallet from its saved configuration and test backups in a separate test environment. Check its policy and transaction history, then rehearse spending using each intended pair of signers. Do not wipe a real working wallet.

Record failures and resolve them before committing real funds. Keep test records clearly separated while learning; when finished, retire the disposable wallet and its records. Never promote a test seed into a mainnet backup.

Pause and check: Stop if the network is unclear, you are using real wallet secrets, or recovery depends on missing configuration. This rehearsal can be done before funding even though the guide introduces backup concepts earlier.
