Practice the complete transaction before relying on it.

Prepare a disposable rehearsal

Use the testnet rehearsal first, with three disposable keys and a verified 2-of-3 wallet configuration. Never use a funded wallet’s seeds for a practice exercise. A successful practice spend is not a full recovery audit.

Keep the online coordinator watch-only. Each signer needs the correct wallet policy and relevant key information; restoring a seed alone does not establish the intended multisig wallet. Follow the documented setup for your particular signer.

1. Build and inspect

In the online watch-only wallet, choose the destination, amount and fee, then export the unsigned PSBT. Record the intended payment using destination information obtained independently from the recipient, not just copied from the coordinator display.

A PSBT carries transaction and signing information. It is not a seed backup and can expose financial metadata. Transfer only the intended transaction file, never a wallet containing private keys.

2. Verify before the first signature

On the first trusted signer, check the network, wallet policy, full recipient address, amount and total fee. Account for every output: any change must return to the verified wallet. Stop if the signer cannot identify change or explain an output.

Use the signer’s documented transaction review. Paper notes help compare intent but do not make a compromised computer trustworthy. For the Tails software-signing workflow, start in Offline Mode and load only this signer’s secret. Export the partially signed PSBT, then fully shut down.

3. Review again with the second signer

Use a different key belonging to the same verified 2-of-3 wallet. Review the same transaction independently, including all outputs and the fee, before signing. A file name or signature count alone is not verification.

For software signing, use a fresh offline session. Rebooting the same computer does not provide independent hardware or remove a firmware compromise. Do not collect both seeds in the online coordinator or one saved wallet file.

4. Finalize and broadcast

Return the signed PSBT to the online coordinator, finalize it when the required signatures are present for every input, and review the resulting transaction before broadcasting. Watch for confirmation on the selected network.

If any field changes unexpectedly, stop and investigate. Do not sign a replacement you have not reviewed. Record what worked and rehearse recovery separately before funding a real setup.

Pause and check: Stop if the wallet policy is uncertain, an output is unexplained, a fee is unexpected, or a signing secret reaches an online environment.
