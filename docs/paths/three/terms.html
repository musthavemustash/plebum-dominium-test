You will need: Nothing, just read

The words you need before the work begins.

Use these definitions as a reference throughout the guide. No secrets are needed to search.

12 terms shown.

Seed phrase
A human-readable backup used to derive wallet keys. Keep it secret. Recovery may also require a passphrase and, for multisig, the wallet configuration.
Passphrase
An additional secret used with a BIP39 seed phrase to derive a different wallet. The exact value matters: a typo can open a different, empty wallet. It is not the device PIN.
Entropy
Unpredictable input used to generate keys. Correct dice collection can provide entropy; it does not protect against malicious software that handles the result.
BIP39
A specification for encoding entropy and a checksum as a mnemonic and deriving a seed from it, with an optional passphrase. It is more than a word list.
Airgap
Separation from networks. In this guide, secret-handling sessions use verified offline software. Turning networking off does not prove the computer is free of malware.
Hash · file fingerprint
A digest used to detect file changes. A match is useful only if the expected value comes from a trustworthy source; an attacker can replace both a file and its published hash.
Digital signature
A cryptographic check that a file was signed by a particular key and has not changed. Verify the signer’s key fingerprint independently; “Good signature” alone does not identify a trustworthy author.
Extended public key · xpub
Public information that can derive a branch of wallet addresses. It does not authorize spending on its own, but revealing it can expose wallet activity.
Wallet descriptor
A description of the scripts and public-key information used by a wallet. A watch-only descriptor is not a signing secret, but it is privacy-sensitive and important for multisig recovery.
2-of-3 multisig
A wallet policy requiring signatures from two of three keys. Recovering with two seeds also needs the missing cosigner’s public information and the correct policy.
PSBT
Partially Signed Bitcoin Transaction: a format for carrying transaction details and signatures between wallet software and signers. It can be used with single-signature and multisig wallets.
Watch-only wallet
A wallet holding public information so it can display addresses and transactions. It cannot sign by itself. Verify its receive addresses against independently trusted wallet details.
