Make the three keys

Time30-45 min
DifficultyModerate
Steps6 sections

You will need: 5 dice · Paper and pen · The worksheet

You will need for offline testing: Dice converter HTML · Python dice converter

Save these files before disconnecting. Public test data only; tools remain under review. Full offline kit and instructions →

Learn how dice rolls become three separate 24-word seed phrases. During this public review, follow the method with the supplied public test rolls and mnemonic fixtures. Label every record TEST ONLY; these tools and instructions remain under review.

These are learning records for the disposable rehearsal ahead. Never use public fixtures or practice keys for real funds. Read Build the 2-of-3 to understand the structure, then choose the practice network and create the separate test wallet on Set up a test wallet.

Safety first: Never enter seed words on an online computer. Boot Tails with networking Disabled before you start. Shut down fully between each key.

What you will do

  1. Boot Tails offline. Copy the dice converter page.
  2. Roll dice. Enter the faces. The page counts to 256 bits.
  3. Write down the 24 words. Prove them with a second tool.
  4. Repeat for Seed 2 and Seed 3, with a full shutdown between each.

Step 1 / 6

Boot Tails. Copy the converter.

Boot Tails with networking set to Disabled. Copy the checked dice converter page from the data USB to the Desktop.

Check: Open only the verified local copy after enabling Tails Offline Mode. An offline indicator alone does not prove network isolation. If it reports online, stop.

Step 2 / 6

Roll the dice. Enter the faces.

Roll five dice at once. Enter each face as you roll it. Using fair, independently rolled dice and a fixed reading order, faces 1 to 4 count as bits (1=00, 2=01, 3=10, 4=11). Faces 5 and 6 are skipped, roll those dice again. The page counts the pairs and stops you at 128.

Roll as many times as needed to get 256 bits of entropy: about 39 shakes.

Check: The page shows 128 pairs and 256 bits. Count accepted pairs, not an estimated number of shakes.

Step 3 / 6

Write the 24 words.

At 256 bits the page prints 24 words. In a 24-word BIP39 phrase, the last word contains three entropy bits and eight checksum bits. It is not an arbitrary check word: never invent or alter it. Write all 24 on the grid. Compare them privately in order, away from cameras and microphones.

Check: All 24 words and their positions are recorded accurately; a valid checksum does not prove safe randomness.

Step 4 / 6

Prove it with a second tool.

Use a separately verified offline implementation with the exact same 256-bit entropy and BIP39 settings. Raw dice inputs are not interchangeable between tools: some hash the roll string while this guide maps accepted faces to bit pairs. Confirm the input method before comparing all 24 words. If you cannot establish that the inputs and method match, stop; do not guess or choose a preferred output.

Check: Both tools show the same 24 words.

Step 5 / 6

Shut down. Start the next key.

Shut Tails down fully. Wait until the screen is dark. Then boot again for Seed 2. New rolls, new words. Repeat for Seed 3. Never continue a list from the previous boot.

Check: Each seed has its own 24 words on its own grid. Three grids total.

Step 6 / 6

Confirm the checks agree.

The checksum detects many transcription errors, but not all of them. It does not authenticate the source of the words. At least two checks must agree: the two tools showing the same words, and the wallet (Sparrow or Electrum, offline) opening the list without error. If anything disagrees, stop.

Stop if: The page says online. The two tools show different words. The wallet rejects the list. Any of these means stop and start that key over.

Public examples only. Never use or share real seed words, private keys, passphrases, funds, wallet details, or personal recovery locations.

  1. P-DICE-01

    Using only public practice rolls, enter 1, 2, 3, and 4, then try 5 and 6 in the linked converter. Check buttons, keyboard entry, counters, Undo, and Clear.

    Expected: The documented mapping is 00, 01, 10, 11; 5 and 6 add no bits. Counters and Undo/Clear stay consistent. Report actual results for each input method.

    Evidence: Use a short recording or screenshots of public rolls; include browser and operating system.

  2. P-DICE-02

    For T3, paste a public 255-bit string. In a separate case, replace one bit of a public 256-bit string with x. Clear the converter before each case.

    Expected: Short and non-binary inputs are rejected without producing a valid mnemonic. Report stale output or unexpected acceptance.

    Evidence: Show the public input length or invalid character and the displayed response.

  3. P-DICE-03

    For T3, convert each supplied public hex fixture to exactly 256 binary digits, preserving leading zeros. Compare each generated mnemonic with the fixture.

    Expected: Every completed fixture matches word for word. Report how many fixtures and which tools were checked; incomplete checks are not a pass.

    Evidence: Record fixture IDs, tool versions, and expected versus actual results; use only public vectors.
