If you get stuck

← 13 · If I am goneStep 14 of 16 · If you get stuck15 · Tough questions →

Find the problem, preserve what still works, and stop when the next step is uncertain.

What setup is this?

A 2-of-3 wallet uses three distinct signing keys; any two can authorize a spend under the correct wallet policy.

What recovery information matters?

Keep the complete wallet configuration and all three cosigner public records as well as the signing backups. Losing two signing keys can prevent spending; losing configuration is a separate recovery problem. Three seeds do not guarantee automatic reconstruction.

The download or version does not match

Stop before running it. Confirm the exact release, file, signature and full hash from the intended publisher. Do not assume a newer release is compatible or an older release is safe. The staging download inventory has unresolved mismatches; see Downloads.

The two converters disagree

Preserve the original rolls privately. Check transcription, input method, bit order and settings. Do not guess a replacement word or choose whichever output you prefer. Use public test vectors before trusting the procedure; funded-wallet backups must not be edited to make a check pass.

The restored wallet looks empty

Stop before wiping or discarding anything. Check the network, account, script type, derivation settings, passphrase if used, and synchronization. Preserve working devices and backups while investigating. Never send secrets to someone offering recovery help.

Where should secrets be kept?

Keep signing secrets offline and protected from theft and loss. Avoid photographs, email, cloud notes and online forms. Plan durable copies and separate locations, then test recovery. A location card is not a substitute for the backups.

How can a helper prepare?

Practice with a disposable wallet and a private written plan. Use the recovery planning guide where it matches your wallet. Never paste real seeds, passwords or passphrases into this site.
