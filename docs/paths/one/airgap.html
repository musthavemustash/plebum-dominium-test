Separate online preparation from offline secret handling.

This page explains the session boundaries. Read Check the files and complete verification before installing or running downloaded software. Page order is not permission to skip that check.

Limits: Tails and Offline Mode cannot make compromised hardware or firmware trustworthy. Reusing one computer for several keys creates shared risks that a reboot does not remove.

Online preparation

Download and verify first

Follow the official Tails installation instructions for your computer and release. Authenticate the image before writing it. Keep a separate data USB for the specific verified files you need.

Do not put seed phrases, raw entropy, private keys, or passphrases on the data USB or in the everyday operating system. Do not create or unlock Persistent Storage for this guide’s temporary secret-handling sessions.

Offline session

Set the boundary before secrets

At the Tails Welcome Screen, enable Offline Mode before starting the desktop. Older instructions may call this networking disabled. Disconnect network cables and do not enable networking during the session.

Use only the verified local tools required for the task. A webpage’s “offline” badge is a reminder, not proof of network isolation or a safe computer.

One key or three?

The one-key path creates one seed. The three-key path uses a separate session for each seed. Do not load multiple signing seeds in one session. Separate sessions reduce accidental mixing; they do not establish independent hardware trust.

Transfer boundary

Export only what the next step needs

When the guide calls for a transfer, export only reviewed public wallet information or the required transaction file. Public descriptors and xpubs expose wallet activity and still need privacy protection.

Never copy seeds, raw entropy, private-key exports, or secret-bearing wallet files back to the online computer. Do not assume a file is public because its name says “backup.” Inspect the export type and follow the wallet’s documentation.

End the session

Power off fully

Finish the offline task and shut down Tails completely before another key session. Do not substitute suspend or hibernate. Keep your physical backup private, away from cameras and microphones.

Shutdown ends the session; it does not undo a disclosure, erase a file you saved elsewhere, or remove malicious firmware. If isolation or software integrity is in doubt, stop and investigate before using that key.

Stop if: verification is incomplete, networking was enabled while a secret was present, a secret was saved to transfer media, or you cannot identify what an export contains. Do not use a real funded wallet for a rehearsal.
