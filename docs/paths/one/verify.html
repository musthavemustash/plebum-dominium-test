Check the files

← 5 · Two bootsStep 6 of 12 · Check the files7 · Make one key →
Time30 min
DifficultyCareful
Steps7 sections

You will need: The downloaded files · Two verification tools

Every file gets checked before the computer goes offline. A file that fails is deleted, no exceptions. A compromised file compromises the funds.

Safety first: These instructions only protect you on plebumbtc.io. Check the address bar. The domain must read exactly plebumbtc.io. Click the lock icon and confirm the certificate. If anything looks wrong, stop.

What you will do

  1. Download each file only from the real sites.
  2. Compare fingerprints. They must match exactly.
  3. Check the signature. Want: "Good signature".
  4. Run the kit check. One failure stops the work.

Step 1 / 4

Download only from the real sites.

Download each file only from the project's own site. The HTML tool pages are the files this site provides; their fingerprints are in VERIFY.md. They are on the downloads page.

Check: Every file came from its official source. No mirrors, no copies.

Step 2 / 4

Compare the fingerprints.

No command line: Open the verify page, pick the file, and drop your download on it. MATCH means it is the published copy. NO MATCH means delete it and download again.

Command line: Run shasum -a 256 (Mac) or Get-FileHash (Windows). Compare every character with VERIFY.md.

Check: Every character matches. One character off means delete the file.

Step 3 / 4

Check the signature.

Import the signing key, confirm its fingerprint, then verify. The "not certified" warning is normal on first import. What matters: the line says Good signature and the fingerprint matches.

Check: "Good signature" appears. The fingerprint matches the download page.

Step 4 / 4

Run the kit check.

Put the downloads next to the verify script and run it. It checks the pinned fingerprints. One failure: the work stops.

Stop if: A fingerprint differs by one character. The signature isn't Good. The two tools disagree on the words. Delete the file, stop the work.
