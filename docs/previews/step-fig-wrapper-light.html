.step-fig wrapper: dark panel to light card

Many handout pages wrap their SVG figures in .step-fig { background: #0e0c09; }, a near-black panel. The SVGs inside mostly use CSS variables and adapt, but the wrapper itself stays dark in light mode. The fix is one line.

The change

CSS: .step-fig { background: var(--card); }, plus a 1px solid var(--line) border to keep the card edge visible on the paper background. The inner SVG should keep using CSS variables so its text picks up the theme.

Affects 8 handout pages that use the .step-fig wrapper, including sparrow, verify, airgap, threat-model, inheritance-easy, and inheritance-one.
