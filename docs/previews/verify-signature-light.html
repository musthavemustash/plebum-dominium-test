check-signature figure: dark terminal to light terminal

The verify page shows a terminal screenshot of the GPG signature check. The source SVG is hardcoded dark: a #080706 background, copper #c9a35c command text, and bright green #4ade80 output. This mock keeps the same content in a light terminal.

Source: templates/verify-figs/check-signature.svg. Live on https://plebumbtc.io/handouts/verify.html.
